# 新版前端操作導覽

[English](FRONTEND_TOUR.md) · [README](../../README.zh-TW.md)

本導覽以一份短篇研究筆記，介紹 ModuTeX 0.3.0 的編輯與編譯流程。可將[示範文件](../examples/frontend-tour/main.tex)複製到獨立資料夾練習，讓編譯產物留在儲存庫之外。

![視覺草稿與 PDF 預覽](../images/workbench.png)

## 1. 建立並儲存文件

從空白文件或範本開始，也可以直接開啟示範 `.tex`。新草稿按「儲存」後，選擇本機位置並以 `.tex` 副檔名保存。視覺與原始碼模式修改的是同一份文件，不會另外建立視覺格式檔案。

## 2. 輸入文字與復原

在「視覺化」模式點選文字儲存格，直接輸入內容。Enter 在格內換行；需要獨立區塊時，再用儲存格的「上方」或「下方」插入控制。新增儲存格不會複製目前文字或既有空白行。

預設以 Ctrl+Z 復原、Ctrl+Shift+Z 重做。切換到原始碼模式後仍共用這份編輯歷史；快捷鍵可在設定中調整。

## 3. 插入公式、表格與程式碼

工具列可開啟公式、表格、程式碼與圖片工具。建立公式或矩陣後，完成編輯才會套用到文件。表格可調整行列及欄寬，程式碼區塊則保留輸入內容與所選語言。

視覺模式提供可編輯的草稿，方便整理內容與結構。最終字型、間距及分頁仍以編譯後的 PDF 為準。

## 4. 切換原始碼

需要載入套件、調整導言區或修改自訂巨集時，將同一編輯區切換成「原始碼」。右側 PDF 會保留，可繼續對照。切回視覺模式後，可編輯已辨識的內容；不支援的語法仍可在原始碼處理。

![原始碼模式與右側 PDF](../images/source-editor.png)

## 5. 設定標題日期

進入「設定 → 編譯」，在「文件日期」選擇格式，再按「套用日期設定」更新主 TeX 文件。套用屬於文件編輯，儲存後再編譯。

| 選項                 | 結果                                        |
| -------------------- | ------------------------------------------- |
| 不顯示日期           | 保留空日期指令，避免 TeX 自動加入當天日期。 |
| 自動日期：YYYY-MM-DD | 以連字號分隔數字年、月、日。                |
| 自動日期：YYYY/MM/DD | 以斜線分隔數字年、月、日。                  |
| 自動日期：DD/MM/YYYY | 以斜線分隔數字日、月、年。                  |
| 自動日期：依文件設定 | 使用 TeX 的日期格式，語言由文件與套件決定。 |

文件原本有自訂日期時，選單會顯示停用的「保留現有自訂日期」，避免直接改寫。自訂語法請到原始碼修改；三種數字預設格式不會加入特定語言的月份名稱。

![工作區編譯設定](../images/compile-settings.png)

## 6. 編譯並檢查 PDF

按「編譯 PDF」執行本機編譯。內建 Tectonic 可能下載尚未快取的 TeX 資源，首次編譯或新增套件時請保持連線。

成功後在右側檢查排版；失敗時查看診斷訊息，預覽區會保留前一次成功的 PDF。之後若再修改文件，請重新編譯，確認 PDF 對應最新內容。

詳細處理方式見[編譯說明](COMPILATION.md)，支援範圍見[已知限制](KNOWN_LIMITATIONS.md)。[影片錄製流程](../media/RECORDING.md)使用同一份示範文件。
