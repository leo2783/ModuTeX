# Settings surface

Scope: approved A settings screen; Operate; local document editor preferences. No redesign of the selected world.

## Direction contract

THESIS: change editing preferences without interrupting or recreating the open document. Controls apply real settings; no unavailable actions.
OWN-WORLD: inherit approved A neutral canvas, blue-grey focus and system UI type; aligned labels, input column and restrained section rules.
STORY: choose appearance or editor display, see it apply, return to the same document and undo history. Persistence failures remain explicit.
FIRST VIEWPORT: global navigation, narrow category rail, scrollable settings form; appearance and editor sections use native selects, numeric input and checkboxes. No decorated preview cards.
FORM: user-pinned A settings image, docs/design/concepts/a-states-2026-10-07/settings.png; no new seed. Initial implementation wires appearance, source font size, line numbers and wrapping. Remaining plan controls are still required, not faked.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Keyboard scope now includes a native compile-binding selector: Ctrl/Command+Enter, Ctrl/Command+Shift+B, or disabled. A separate per-field preference uses the existing validation and storage-event policy. Ctrl/Command+O opens through the current real picker; Ctrl/Command+S uses the existing save path. Composition, repeated keys, prevented events, and non-editor form inputs must retain their behavior. Language, autosave, cache, system TeX and desktop input acceptance remain pending.
