# ModuTeX 產品簡報

來源：[核准計畫](../architecture/FRONTEND_REWRITE_PLAN.md)。先圖片稿，使用者選擇後實作 UI。

本機 LaTeX 文件工作台：開啟專案、編輯、插入公式與表格、編譯與閱讀 PDF。未修改文件原樣儲存；未知語法保留。頁面為首頁、工作台、設定、說明；工具狀態含來源對照、PDF／診斷、表格、公式／矩陣。

文件與 PDF 為焦點，常用操作集中，設定按需展開。無螢光色、宣傳漸層、裝飾統計或重複文案。

淺色：canvas #F4F3EF、surface #FFFFFF、text #24292E、muted #5D6670、border #CDD2D7、accent #3D617B、error #A33232。

深色：canvas #202428、surface #292E33、text #E8EBED、muted #AFB8C0、border #49525B、accent #9BBAD1、error #EF9696。使用系統 UI 字型。

Draw.io、Mermaid、MCP、視覺章節折疊不在本階段承諾。圖片稿不是功能；桌面驗收須真實適配，不使用 mock 冒充。新版與 legacy 分開，不複製上游、不宣稱整個 App 已換授權。
