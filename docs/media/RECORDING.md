# 新版前端影片錄製流程

影片由維護者錄製。本次文件變更不包含影片，也不在 README 放置尚未上傳的影片連結。

## 準備

從 `dev` 的已驗證版本執行 `npm run build`，再以 `npm run tauri` 啟動。將[示範文件](../examples/frontend-tour/main.tex)複製到獨立資料夾，用 ModuTeX 開啟。先成功編譯一次，確定所需 TeX 資源已下載，並關閉含私人路徑或訊息的面板。

## 建議鏡頭

| 順序 | 操作                                                    | 確認畫面                         |
| ---- | ------------------------------------------------------- | -------------------------------- |
| 1    | 開啟示範文件並顯示 PDF。                                | 左側視覺草稿、右側編譯結果。     |
| 2    | 在文字格輸入一句話，以 Enter 接續下一行，再復原與重做。 | 換行可接續輸入，內容可連續復原。 |
| 3    | 開啟偏導數公式，修改後完成編輯。                        | 公式在文件中更新。               |
| 4    | 檢視表格與 Python 程式碼。                              | 表格行列與語法標亮。             |
| 5    | 切到「原始碼」，再切回「視覺化」。                      | 同一文件與右側 PDF 保持可見。    |
| 6    | 在編譯設定選擇數字日期、套用，然後儲存。                | 所選日期規則寫入主文件。         |
| 7    | 按「編譯 PDF」並檢查結果。                              | 標題日期與最新修改出現在 PDF。   |

完成後可回到「不顯示日期」並復原示範文字，讓文件恢復原始狀態。影片建議使用 MP4/H.264，保留足夠解析度讀取工具列與公式；上傳確認可播放後，再將影片連結加到雙語 README 的「操作示範／See it in use」。
