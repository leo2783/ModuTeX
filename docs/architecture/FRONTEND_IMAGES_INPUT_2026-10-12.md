# 圖片、輸入與表格修正（2026-10-12）

## 功能與邊界

圖片工具接受 PNG／JPEG；視覺與原始碼編輯器皆接受圖片貼上。點選圖片後 Ctrl+C 會保留內部剪貼資料的原始位元組，並提供系統 PNG 格式。JPEG 僅在複製時轉換，避免開啟文件就建立額外點陣資料。

桌面圖片寫入文件所在資料夾；未儲存文件先選擇儲存位置。瀏覽器版本以 IndexedDB 保存資源。插入圖片及補上 graphicx 共用一次來源交易與復原；取消或切換文件不套用遲到結果。

| 邊界 | 行為 |
|---|---|
| 容量 | 每張 5 MiB；另存圖片合計 32 MiB、最多 4096 個資源 |
| 格式 | 前端解碼；檔案介面驗證 PNG／JPEG 標記及副檔名 |
| 路徑 | UUID 檔名，沿用工作區、連結、路徑、修訂與衝突限制 |
| 另存 | AST 收集受管理圖片，先複製資源再發布文件；同內容重用，異內容同名拒絕覆蓋 |
| 失敗 | 可能留下未引用的新資源；不刪除無法確認歸屬的檔案 |
| 檔案樹 | 維持 TeX／PDF 清單，此次僅增加圖片讀寫 |

## 從底層移除數學鍵盤

MathLive 0.110.0 為 MIT 第三方依賴。`apps/frontend/scripts/mathlive-input-only.mjs` 在建置時移除八個 virtual-keyboard 模組、公開掛載 API、切換按鍵及按鈕標記。上游 SHA-256 為 `5102f07f98461e1e34605bc81362dce2343dade9d60b6c311f1109b7f89c7374`；內容改變時拒絕建置，必須重新審核。

非視覺生命週期接點與實體鍵盤輸入保留，但不註冊 `window.mathVirtualKeyboard`，也不建立鍵盤、版面或跨窗訊息。Vite 產生 input-only runtime 與可追溯 source map；MathLive 授權全文及 20 個字型資產保留。這是明確標示的第三方修改，不宣稱嚴格 clean-room。
