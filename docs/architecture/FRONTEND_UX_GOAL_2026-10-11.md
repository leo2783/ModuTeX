# 前端重構：功能完整與操作層級

## 本輪目標

**狀態：數學功能完整性本輪修正及驗收完成。** 最新功能與 AGY3＋API Luna3 收據見 [數學與內容編輯驗收](./FRONTEND_MATH_PARITY_2026-10-11.md)。 90d7829 之後使用者要求的工具列、文件內公式、側欄上下分區及 PDF 回饋已修正；本輪另行驗證，見 [文件內編輯驗收](./FRONTEND_INLINE_ACCEPTANCE_2026-10-11.md)。

最新要求：視覺化預設且圖示優先；模式、格式與插入共用一列，移除重複「文件」列。公式在文件內編輯；數學入口合併行內公式、公式儲存格與矩陣；展開常見公式、希臘字母、lim、積分／微分與多行函數。支援程式碼儲存格與文字顏色，確認綠色、取消紅色。左側檔案總管與大綱上下同時顯示。編譯有可見進度與成功／失敗訊息，成功 PDF 必須完成真實 canvas 繪製才宣告已更新。僅修改前端，沿用現有後端與 IPC。

最新必須完成：每格可選取、編輯、完成／取消、刪除、上下移動、上方／下方新增；文字、公式、矩陣、表格共用文件與 undo。選取依實際內容範圍，操作立即回應；背景解析不應鎖住關閉或讓畫面持續閃動。移除數學鍵盤入口，核對並沿用使用者明確確認為其原創的 0.1.0 matrix 程式與設計，維持第三方部分的來源界線。

保留既有功能與設計概念，以自行實作的前端提供清楚層級、直覺操作與直接文件編輯。後端模組與 IPC 重寫留待後續；新版使用現有介面，不透過降級或隱藏缺失達成授權目標。Electron 載入與部分主流程通過，只是其中一項證據。

## 功能層級

| 層級 | 入口與行為 |
| --- | --- |
| 文件 | 新增、開啟、最近文件、儲存、另存；未保存內容有明確狀態與切換保護 |
| 編輯模式 | 視覺化優先、原始碼可切換；與格式／插入共用一列，以分隔線區分功能；移除對照 |
| 文件內容 | 直接編輯文字；在區塊之間新增文字、公式、矩陣、表格、程式碼；行內公式保留游標，共用來源與 undo |
| 格式 | 粗體／斜體／底線／文字顏色圖示與 tooltip；保留可存取名稱、選取與焦點 |
| 編譯／PDF | 編譯、取消、錯誤定位、預覽與上一份成功 PDF 的關係清楚 |
| 次要工具 | 設定、說明、版本資訊不混入主要文件操作；導覽可閱讀 |

## 停止條件

1. 核對功能對照，不把後端既有能力誤列為新版已接入；未接入項目明確列出與處理。
2. 真 GUI 完成新增／開啟、文件內編輯、區塊插入、公式／矩陣／表格、保存與 undo、編譯／取消／錯誤復原／PDF。
3. 深色／淺色與實際桌面寬度下，模式可找到、說明分類可閱讀，主要流程不用猜入口。
4. 不匯入第三方 legacy UI；使用者確認為其原創並授權重用的 matrix parser 可直接沿用，記錄來源。不更改 root 授權。
5. 只提交已驗證內容，依 CONTRIBUTING commit／push；維護 method，記錄真 AGY3＋API Luna3 handles 與交付。
