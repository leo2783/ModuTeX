# 前端重構：功能完整與操作層級

## 本輪目標

保留既有功能與設計概念，以自行實作的前端提供清楚層級、直覺操作與直接文件編輯。後端模組與 IPC 重寫留待後續；新版使用現有介面，不透過降級或隱藏缺失達成授權目標。Electron 載入與部分主流程通過，只是其中一項證據。

## 功能層級

| 層級 | 入口與行為 |
| --- | --- |
| 文件 | 新增、開啟、最近文件、儲存、另存；未保存內容有明確狀態與切換保護 |
| 編輯模式 | 原始碼、視覺化固定可見，與格式／插入工具分開；依使用者修正移除對照 |
| 文件內容 | 直接編輯文字；在區塊之間新增文字、公式、矩陣、表格；共用來源與 undo |
| 格式 | 熟悉的圖示與 tooltip；保留可存取名稱、選取與焦點 |
| 編譯／PDF | 編譯、取消、錯誤定位、預覽與上一份成功 PDF 的關係清楚 |
| 次要工具 | 設定、說明、版本資訊不混入主要文件操作；導覽可閱讀 |

## 驗收狀態

模式分區、格式圖示、Help 導覽、真正 MathLive 渲染、區塊插入與未儲存關閉已整合；完整回歸 327／327，真 Chrome 6／6。最終建置、原生主流程、來源邊界與審查限制見 [驗收記錄](./FRONTEND_UX_ACCEPTANCE_2026-10-11.md)。獨立來源與完整應用授權審查未核准，不能宣稱整體去除 AGPL。

## 停止條件

1. 核對功能對照，不把後端既有能力誤列為新版已接入；未接入項目明確列出與處理。
2. 真 GUI 完成新增／開啟、文件內編輯、區塊插入、公式／矩陣／表格、保存與 undo、編譯／取消／錯誤復原／PDF。
3. 深色／淺色與實際桌面寬度下，模式可找到、說明分類可閱讀，主要流程不用猜入口。
4. 不複製 legacy 程式碼，不更改 root 授權；原創前端来源與第三方依賴另行核對。
5. 只提交已驗證內容，依 CONTRIBUTING commit／push；維護 method，記錄真 AGY3＋API Luna3 handles 與交付。

## 品質審查基準

| 項目 | 可判定標準 |
| --- | --- |
| 功能完整 | 每項功能有可操作入口與結果；不把後端已有 API 當成前端已接線 |
| 層級 | 文件操作、模式、內容插入／格式、編譯、次要頁面分區；不堆更多平行按鈕 |
| 文字 | 同一功能同一名稱；短而具體；不用 parser／IPC／架構作為主要使用者訊息 |
| 視覺化 | 正常操作無需輸入或閱讀 LaTeX；未支援語法保留，不能默默改寫或刪除 |
| 配色 | 共用 tokens；靜態文字／選取狀態在深淺色對比足夠，實際 hover／focus／disabled／error 另以 GUI 核對 |
| 資料正確 | 原 bytes、preamble、未知語法與相鄰區塊保持；單一來源與 undo；取消、儲存失敗不丟稿 |
| 效能 | 大文件編輯不隨 caret 移動全量重建；延遲載入重元件，保持 production 預算 |

靜態 token 對比（文字對 surface）：淺色正文 14.67、次文字 5.83、accent 6.57；深色正文 11.44、次文字 6.81、accent 6.74。選取 accent 為淺色 5.45、深色 4.81。這些數值不是整個 GUI 已通過的證據。
