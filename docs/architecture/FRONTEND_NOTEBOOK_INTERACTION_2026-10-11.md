# 儲存格與公式互動修正

## 行為

- Escape 切到儲存格選取；上下鍵選取相鄰儲存格，Enter 回到輸入。Alt＋上下鍵移動儲存格，與滑鼠上移／下移共用來源交易。移動後待新版本解析完成，選取跟隨移動結果。
- 公式／表格／程式碼編輯事件停止冒泡；關閉局部草稿同步刷新控制項。新增公式可連續重編輯，避免文件選取覆寫 MathLive 焦點。
- 數學選單先選種類、再選公式，提供返回種類；選完收起。希臘大小寫合併，191 個項目不減少。選單在輸入區下方正常排版，行內草稿的工具列與輸入上下排列。
- 工具按鈕保留輸入焦點；未主動選取公式時，模板不擅自把前一段公式包進新結構。
- 程式碼提供純文字、Python、JavaScript、TypeScript、C、C++、JSON、Shell、SQL。純文字使用 verbatim，其餘使用受限 lstlisting metadata；重新編輯還原語言。只顯示內容、不執行，不使用 shell-escape。
- listings 套件與程式碼內容同一筆 undo。僅接受固定語言及產生的 metadata；未知 listing 選項保留 Raw。JavaScript／TypeScript／JSON 沒有宣稱已提供完整語法高亮。
- 視覺編輯時將緊貼正文的 end{document} 分隔至下一行，採來源換行策略，與該次輸入共同 undo。沒有編輯的原檔不自動格式化。新分隔線不納入可編輯內容的局部來源映射。
- 欄寬把手改為帶邊框的左右箭頭，hover／focus 加強顯示；保留拖曳、方向鍵、觸控與可存取名稱。

## 根因與來源

新增公式編輯按鈕的事件原先會觸發文件層選取；儲存格移動後則使用舊游標位置恢復選取。修正事件邊界與帶文件版本的移動選取，沒有重寫後端或 IPC。

本批為新版前端獨立實作，未讀取或複製 legacy 實作。主代理整合六份實際回件；代理只讀目前新版來源，未直接改檔。
