# 文件內編輯與 PDF 回饋驗收

本輪僅重構前端，沿用既有桌面後端與 IPC；承接使用者對前輪 Notebook 交付的修正要求。

| 操作 | 結果 |
| --- | --- |
| 進入工作台 | 預設視覺化；圖示模式、格式與插入共用工具列，移除重複文件列。 |
| 公式／矩陣／表格圖示 | 在目前儲存格下方開啟新格編輯；完成才寫入來源，取消保留原文。 |
| 文件內公式 | 在原位置編輯，支援 Enter 完成、Escape 取消，沒有虛擬鍵盤入口。 |
| 儲存格 | 保留上下新增、移動、刪除與共用復原；取消刪除保留選取。 |
| 檔案導航 | VS Code 式巢狀檔案樹，上方檔案總管、下方大綱，各自捲動。 |
| 編譯 PDF | 顯示編譯中、成功、失敗與取消；成功自動顯示最新 PDF，畫布完成後才提示「PDF 已更新」。失敗保留上一份成功 PDF。 |
