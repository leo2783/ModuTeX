# 表格欄寬調整

> 歷史實作／審查紀錄。下列測試數字與待辦反映早期改寫階段；現行功能、版本及目錄以[實作狀態](FRONTEND_REWRITE_STATUS.md)與[開發指南](../user/DEVELOPMENT.md)為準。

`TablePanel.svelte` 在表格上方提供相鄰欄位的拖曳邊界，沿用數字比例輸入。`column-resize.ts` 只交換該兩欄的比例，保留其他欄及兩欄總和。極窄欄位不在開始拖曳時跳動；兩欄保持正值且符合來源生成器的上限。

| 操作 | 行為 | 驗證界線 |
| --- | --- | --- |
| Pointer 拖曳 | 開始時捕捉單一 pointer，以起點座標與欄寬快照計算，其他 pointer 不接管 | 數學／owner 模型測試，不是瀏覽器 capture 證據 |
| Left／Right | 每次交换表格總比例 1%；Shift 為 5%，到邊界時夾限 | 已接線，桌面鍵盤／焦點待验收 |
| Cancel／失去捕捉／blur | 結束拖曳，保留目前草稿；晚到 movement 不更新 | 狀態模型測試，實際觸控與視窗切換待驗收 |
| 關閉／取消／套用／卸載 | 撤銷 owner、釋放 capture；草稿仍走既有套用交易 | 接線與型別通過，Electron 重開／undo 待驗收 |
| 增刪行列／數字改寬 | 先停止拖曳再調整草稿，避免舊權重覆蓋新結構 | 接線已實作，整體 panel 端到端待驗收 |

拖曳期間不寫入 TeX，也不新增專用 undo stack；按套用才走既有來源交易。三項新測試涵蓋交換與夾限、單 owner／取消／重新進入及生成來源回讀，確認儲存格與 caption 不變。前端全套 85／0 skip、型別 0 errors／warnings、正式建置與產物測試 1 項通過；初始 JS 96.50 KB、editor 485.92 KB，門檻未改。Impeccable detector exit 0、無輸出。

未完成：Chromium／Electron 真實幾何與捕捉、觸控、多欄窄版面、100%／150% 縮放、鍵盤提示及完整表格保存重開驗收。沒有以合成座標或狀態模型宣稱實體拖曳已驗收。
